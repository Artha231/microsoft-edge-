Dashboard Simulasi Keamanan Unduhan Blob

Gunakan tombol di bawah untuk menguji respons fitur perlindungan browser terhadap skenario ekstensi berkas berbahaya menggunakan teknik pengolahan Blob lokal.

1. Aplikasi HTML (.HTA)

Menguji apakah browser memblokir unduhan aplikasi berbasis komponen HTML aktif yang menggunakan penyamaran spasi nama.

2. MIME Smuggling (HTML)

Mengirimkan objek teks dengan format HTML/JS internal untuk menguji fungsi deteksi tipe konten asli (*sniffing*) browser.

3. Windows Script Host

Mengirimkan skrip berbasis XML menggunakan pustaka Blob terenkapsulasi untuk menguji peringatan unduhan skrip aktif.

4. Berkas Biner Tiruan

Mengubah keluaran Blob menjadi stream generik berujung ekstensi eksekutabel untuk menguji sensitivitas *Safe Browsing*.
