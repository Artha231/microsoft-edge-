Kenapa ini penting?
• navigator.vibrate() sebenarnya tidak butuh user activation di Chrome/Firefox modern — jadi ia akan selalu berhasil begitu di-ARM, bahkan tanpa gesture apa pun.
• API seperti AudioContext.resume(), requestFullscreen(), navigator.wakeLock.request() memang butuh user activation. Baris "Audio OK" mengukur apakah gesture tertentu cukup untuk "menularkan" aktivasi ke API tersebut.
• Setiap gesture yang terdeteksi dicatat beserta hasilnya, sehingga Anda bisa melihat gesture mana yang paling andal memicu efek samping.
