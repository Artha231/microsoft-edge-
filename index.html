Uji Penyamaran Ekstensi Saat Dialog Save As

Menguji apakah browser menampilkan nama file yang jujur di dialog Save As, atau tertipu oleh trik karakter tersembunyi (RTL override, Unicode, null byte).

1. Ekstensi Ganda Standar

Nama: laporan.txt.html
Dialog akan menampilkan ekstensi lengkap. Sistem operasi biasanya langsung memperingatkan.

2. Ekstensi Ganda + EXE

Nama: gambar.txt.exe
Menguji apakah Windows Defender/SmartScreen memberi peringatan saat file disimpan.

3. RTL Override (Trik Unicode)

Nama: laporan\u202Ehtml.txt
Karakter RTL membuat tampilan di file manager terlihat sebaliknya. Trik klasik malware.

4. Spasi Tak Terlihat

Nama memakai karakter spasi Unicode (U+00A0) untuk menyembunyikan ekstensi sebenarnya.

5. Null Byte Injection

Nama: dokumen.txt%00.html
Uji apakah parser browser/sistem terpotong di null byte (legacy bug).

6. Ekstensi Super Panjang

Nama sangat panjang sehingga ekstensi sebenarnya terpotong di tampilan file manager.

7. Titik Ganda di Akhir

Nama: dokumen.txt.html.
Windows otomatis menghapus titik di akhir — uji apakah ekstensi tersembunyi terungkap.

8. Karakter Kontrol

Nama menyisipkan karakter kontrol ASCII (mis. U+0007 bell) di antara ekstensi.
