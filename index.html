Dashboard Simulasi Keamanan Unduhan Blob

Pengujian teknik MIME sniffing: Blob dideklarasikan sebagai tipe aman, tetapi isi aktualnya berisi konten aktif HTML/JavaScript.

1. Aplikasi HTML (.HTA)

Menguji apakah browser memblokir unduhan aplikasi berbasis komponen HTML aktif yang menggunakan penyamaran spasi nama.

2. MIME Smuggling (HTML)

Mengirimkan objek teks dengan format HTML/JS internal untuk menguji fungsi deteksi tipe konten asli sniffing browser.

3. Windows Script Host

Mengirimkan skrip berbasis XML menggunakan pustaka Blob terenkapsulasi untuk menguji peringatan unduhan skrip aktif.

4. Berkas Biner Tiruan

Mengubah keluaran Blob menjadi stream generik berujung ekstensi eksekutabel untuk menguji sensitivitas Safe Browsing.

5. Sniffing: Teks Biasa

Blob dideklarasikan text/plain, namun isi sebenarnya adalah HTML dengan skrip aktif. Menguji content sniffing browser.

6. Sniffing: Gambar Palsu

Blob dideklarasikan image/png, namun isi sebenarnya adalah dokumen HTML aktif. Menguji spoofing tipe MIME.

7. Sniffing: JSON Palsu

Blob dideklarasikan application/json, namun berisi HTML dengan tag skrip yang akan diproses browser.

8. Sniffing: BOM + HTML

Blob berisi BOM UTF-8 yang disisipkan sebelum dokumen HTML untuk menguji perilaku deteksi awal parser.
